# Карусели: типы слайдов и формулы

Типы (`posts.json` → `slides[].type`): cover · text (body, prompt, chips) · steps (items) · stat (from, to, label) · pwin (фото в окне) ·
chat (msgs) · cards (cards с ценой) · pcode (промпт в терминале) · cta (кодовое слово).
Фон слайда: `theme`: light / cream / dark. Выделение: `<span class="hl">слово</span>`, акцент цветом: `<span class="ac">слово</span>`.

Формулы: экспертная cover → text → steps/chat → stat → cta · кейс cover → stat → text → steps → cta · продающая cover → cards → steps → cta.
5–8 слайдов, одна мысль на слайд, заголовок до 8 слов, чередовать фоны. Цифры — только реальные от владельца.

# Старт за 10 минут

Для тех, кто хочет свой брендбук: логотип, цвета, шрифты, шаблоны постов и рилс. Рисовать и программировать не нужно —
всё делает Claude Code, ты отвечаешь на вопросы и выбираешь по картинкам.

## 1. Что нужно

- Компьютер (Mac, Windows или Linux) и Google Chrome.
- Claude Code (приложение, вкладка Code) с подпиской Pro или Max. Модель — самая новая Opus.
- Аккаунт GitHub, если репозиторий приватный: Куралай даёт доступ.

## 2. Установка одним сообщением

Открой Claude Code в пустой папке и отправь:

```text
Склонируй репозиторий https://github.com/adam-team/brand-builder в папку brand-builder,
подготовь окружение по SETUP.md и сразу начни опрос по docs/agent-contract/WORKFLOW.md.
Я хочу собрать свой брендбук с нуля. Спрашивай по одному вопросу, с вариантами ответа и картинками.
```

## 3. Что будет

1. Вопросы о тебе, клиентах, продуктах и вкусе.
2. Три идеи бренда — выбираешь одну.
3. Картинки с 24 стилями (монохром, дорогой, тёплый, яркий, особенные) — выбираешь номер или присылаешь свои образцы.
4. Три варианта знака — выбираешь.
5. Агент собирает всё и показывает картинки: карусели, обложки рилс, актуальные, стикеры, визитку, сертификат.
6. Получаешь папку `dist/` и `Брендбук.pdf`, плюс `BRAND_GUIDE.md` — его прикрепляешь к ChatGPT или Canva AI.

## 4. Как отвечать

Цифрой варианта, своими словами или голосом. «Не знаю» — нормальный ответ: агент предложит вариант.
Цены, цифры, отзывы называешь только ты — агент их не выдумывает.

## 5. Если агент сбился

```text
Остановись. Прочитай CLAUDE.md и docs/agent-contract/WORKFLOW.md.
Скажи, на каком мы этапе и какие файлы в projects/ заполнены. Продолжай по одному вопросу.
```

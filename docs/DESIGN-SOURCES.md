# Откуда берутся дизайны

Когда агент делает дизайн без образцов, он не «придумывает из головы»: он собирает его из известных систем —
сочетаний цветов, шрифтовых пар, приёмов вёрстки, которые уже работают у сильных брендов. Ниже — где их брать вам.

## 1. Готовые стили в этом репозитории
`patterns/styles.json` — 24 направления (монохром, дорогой, тёплый, яркий, особенные). У каждого: палитра из 11 цветов,
шрифты с проверкой казахских букв, радиус, узор, приём выделения, фирменные элементы и «на кого смотреть».
Можно смешивать: «цвета от 6, шрифты от 21».

## 3. Как сделать «свой стиль» из образцов (вариант 25)
1. Соберите 5–10 скриншотов: сайты, посты, упаковка, интерьер, одежда — что нравится по настроению.
2. Отдайте агенту: он вытащит палитру (5–8 цветов), определит шрифты или подберёт похожие бесплатные,
   опишет приёмы (рамки, узоры, фото, плашки) и соберёт `brand.json`.
3. Проверка: контраст текста ≥ 4,5:1 (брендбук считает сам), казахские буквы (`scripts/check-fonts.py`).
4. Нельзя: копировать чужой логотип, название, фирменный знак. Берём настроение, а не исходник.

## 4. Как агент придумывает дизайн без образцов
1. Ниша и клиент → настроение (дорого / тепло / технологично / ярко).
2. Настроение → группа стилей и 2–3 номера.
3. Идея бренда → фирменный элемент (у Куралай «проект — маршрут» дал линию через всю карусель).
4. Один акцентный цвет + тёмный + 2 светлых + серый. Пропорция 60/30/10.
5. Шрифтовая пара: выразительный для заголовков + спокойный для текста + моно или курсив для деталей.
6. Проверка на реальном посте, а не на палитре: рендер карусели и правки.

# Банк вопросов с вариантами

## Этап 1 · Бриф
- «Чем ты помогаешь людям одной фразой?» — 1) обучаю … 2) делаю за клиента … 3) консультирую … 4) продаю товар … 5) свой вариант
- «Кто твой клиент?» — 1) женщины 25–40 2) предприниматели 3) специалисты/эксперты 4) родители 5) свой вариант
- «На кого НЕ хочешь быть похожей?» — назови 1–3 аккаунта или опиши (слишком гламурно, слишком детски, «как все инфоцыгане»)

## Этап 2 · Идея
- «Какая идея ближе?» — 3 метафоры от агента + «смешать» + «своя»

## Этап 3 · Стиль
- «Какое настроение?» — 1) строгий монохром 2) дорого и спокойно 3) тепло и уютно 4) ярко и смело 5) особенный (медицина, казахский модерн, академия, Y2K, бохо)
- «Номер стиля?» — показать styles-A…E.jpg; 25 — свой
- «Узор фона?» — точки / клетка / линии / диагональ / без узора
- «Как выделять главное слово?» — плашкой / подчёркиванием / цветом
- «Скругления?» — острые / мягкие / круглые

## Этап 4 · Знак
- «Какой тип знака?» — 1) монограмма из букв 2) символ-метафора идеи 3) эмблема-бейдж 4) пиктограмма 5) только надпись

## Этап 5 · Голос
- «Как обращаемся?» — на ты / на вы / в соцсетях на ты, в услугах на вы
- «Кодовое слово для комментариев?» — одно короткое слово, которое ведёт к гайду
